# 3. Problem Solution

Grupo: Educational. Posição 3 no board.

## Ponto de partida, como o board escreve

> Starting Point: These videos start with a problem you want to solve

Fonte: nó `66:157` do board. Em português: o vídeo nasce de um problema que você quer resolver.

Repare no "you want to solve". O board coloca o problema como seu, de quem produz. A peça sai de um incômodo que você reconhece, e não de uma dor que você foi procurar no público.

## Quando usar

Quando a dor é reconhecível em uma frase e a resposta cabe no tempo da peça. O teste: se você precisa explicar por que aquilo é um problema, o formato já está trabalhando contra você.

Quando existe uma solução proporcional. Problema grande com solução de um minuto soa desonesto.

## Quando não usar

Quando o problema é conhecido e a solução é a óbvia. Ninguém precisa de você para chegar lá.

Quando a solução é comprar algo seu. O formato aguenta uma oferta no fim, não uma peça inteira disfarçada.

Quando o erro é do público e não uma situação. Isso é 4. Common Trap / Mistake, e a diferença importa: aqui a pessoa não fez nada de errado, só esbarrou em algo.

## Como executar

1. Nomeie o problema pelo sintoma, do jeito que a pessoa sentiria. Não pelo nome técnico.
2. Mostre a consequência de deixar como está. Sem isso, a peça vira curiosidade.
3. Dê a causa provável. Uma. E diga que é provável, se for.
4. Entregue a solução em passos que caibam na cabeça de quem está ouvindo, não olhando.
5. Diga qual é o sinal de que funcionou. É o que separa conselho de palpite.

## Ângulos que funcionam

Sintoma contra causa. Solução rápida para um travamento específico. Conserto de uma etapa do processo, não do processo inteiro. Problema invisível, que só aparece quando alguém aponta. Solução por etapas quando a dor é grande demais para uma tacada.

## Modo de fala recomendado

Guiado. Abertura fixa no sintoma, movimentos em consequência, causa e solução, fechamento no sinal de que deu certo. O improviso ajuda na parte do sintoma, que é onde a peça precisa soar vivida.
